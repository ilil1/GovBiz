# GovBiz AI runtime

AI HTTP 서비스와 평가 실행기가 함께 사용하는 Python 패키지입니다. 근거 답변의 입력·출력 계약,
원문 검색, 임베딩, LangChain 답변 생성, 추적 및 설정의 구현을 한 곳에서 관리합니다.
FastAPI 애플리케이션이나 Ops/Django 모듈을 가져오지 않습니다.

AI 서비스는 `govbiz-ai-runtime`을 설치하고 기존 `app.*` 경로를 같은 모듈 객체로 연결합니다.
따라서 모델·예외 타입, 모듈 설정, 테스트의 패치가 서로 다른 복사본으로 나뉘지 않습니다.
평가 실행기는 `govbiz_ai_runtime.*`를 직접 가져오며 AI 서비스 소스 디렉터리가 필요하지 않습니다.

의존성은 추출 시점 AI 서비스 잠금 파일의 버전으로 고정했습니다. 배포할 때 wheel에 구현 코드가
포함되므로 저장소 위치나 현재 작업 디렉터리에 의존하지 않습니다. 개발 환경의 상대 경로는
각 소비자의 `tool.uv.sources`에서 설치할 패키지를 지정할 때만 사용합니다.
